Validation notes:
The packaged reflection helper loads the above DLL set and reads the local NVIDIA GPU sensors without a DLL-load error.
CPU temperature is not validated without a loaded PawnIO device and hardware-access permissions. A zero fallback value must be treated as unavailable, not as 0 degrees C.
The official PawnIO 2.2.0 release fixes the older 2.1.0 Windows 10 RS5/19H1/19H2 missing-export BSOD issue. No driver has been installed or tested as part of component preparation.
Do not package sensors/.source into the user distribution: it is scratch download/inspection data including the original LHM GUI archive, not required runtime files.
