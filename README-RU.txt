ORBIT WIDGETS 1.1.2
Круглые прозрачные виджеты производительности для Windows x64.

ЗАПУСК
Откройте OrbitWidgets.exe. Папка sensors должна оставаться рядом с программой.
Установка основного приложения не требуется.
Для установки в Program Files используйте OrbitWidgets-Setup-x64.exe.
Рекомендуемая установка включает подписанный драйвер датчиков PawnIO 2.2.0.
Если подходящая версия уже установлена, установщик пропустит этот шаг.
Настройки и общий драйвер датчиков сохраняются при удалении приложения.

АВТОЗАПУСК
Настройки → Запуск → «Запускать при входе в Windows».
«С правами администратора» задаёт повышенные права при автозапуске.
При изменении повышенного запуска Windows может запросить подтверждение.
Автозапуск выполняется в сеансе текущего пользователя через 10 секунд после
входа; пароль не сохраняется. Включение автозапуска не запускает второй
экземпляр сразу и не изменяет права уже открытого окна виджетов.
Отключение галочки удаляет только собственное задание этой установки.

УПРАВЛЕНИЕ
Правый клик по любому кругу — настройки.
Перетаскивание любого круга — перемещение всей группы.
Ctrl + Alt + O — открыть настройки и разблокировать виджеты.
Ctrl + Alt + L — включить / выключить закрепление с пропуском кликов.
Значок Orbit Widgets в области уведомлений — настройки, закрепление, выход.
Повторный запуск программы открывает настройки уже запущенного экземпляра.

НАСТРОЙКИ
Каждый показатель и каждая буква диска включаются отдельно.
Нагрузка ЦП/ГП — внешнее кольцо; температура — внутреннее.
ОЗУ и диски показывают занятый объём / общий объём и долю заполнения.
Сеть показывает приём (стрелка вниз) и отдачу (стрелка вверх).
Единицы сети: Мбит/с или МБ/с; 1 МБ/с = 8 Мбит/с.
Максимум сетевой шкалы задаётся отдельно от числового текущего значения.
Это текущий трафик выбранного адаптера, включая локальную сеть.
Автоматический выбор использует физические Ethernet/Wi-Fi без сложения VPN.
Объёмы ОЗУ/дисков показаны в двоичных гигабайтах (1024^3 байт).

Можно изменить размер, расстояние, прозрачность, тему, ориентацию,
положение у края/угла и монитор. Если группа не помещается, она переносится
на следующий ряд/колонку. «Поверх других окон» включается отдельно.
В закреплённом режиме мышь проходит через виджеты на рабочий стол.
Новый профиль: вертикально, справа по центру дополнительного монитора,
если он подключён; существующее размещение при обновлении сохраняется.

ТЕМПЕРАТУРА ЦП
Знак «—» означает, что датчик недоступен, а не нулевую температуру.
Сначала программа использует доступные источники показаний. Если MSI
Afterburner уже запущен и публикует температуру ЦП, она читается из его
общей памяти без дополнительных драйверов и повышения прав. Этот источник
работает, пока Afterburner запущен; устаревшие данные не показываются.
Для прямого чтения через LibreHardwareMonitor на некоторых процессорах
(включая Ryzen 7 5700G) нужен драйвер PawnIO и доступ к оборудованию.
Проверенный официальный установщик
PawnIO 2.2.0 находится в optional\PawnIO-Setup.exe.
Если драйвер ещё не установлен, его установка — отдельное действие,
требующее подтверждения Windows. Используйте стандартную подписанную
редакцию. После установки откройте настройки и перезапустите программу
с правами администратора, затем обновите поиск датчиков.
Программа не отключает защиту Windows и не перезагружает компьютер.
Без драйвера остальные показатели работают.

ОБНОВЛЕНИЕ
ЦП/ГП, ОЗУ, сеть — каждые 0,5 секунды; температуры helper — 1 секунда;
занятое место на дисках — каждые 5 секунд.
Данные NVIDIA поступают непосредственно из NVML, без запуска nvidia-smi.
Настройки хранятся локально в %LOCALAPPDATA%\Orbit Widgets\settings.json.
Приложение не отправляет показания в Интернет.

СБОРКА И ИСХОДНИКИ
Исходники основного приложения — Rust, интерфейс egui/eframe.
Модуль температур — небольшой C# helper с LibreHardwareMonitor 0.9.6.
Для сборки выполните build.ps1 в PowerShell при установленном Rust
и средствах сборки MSVC либо MinGW. Cargo.lock фиксирует зависимости.
Лицензия собственного кода — MIT. Лицензии сторонних компонентов
и точные ссылки на их исходники находятся в sensors\licenses,
SENSOR-SOURCES.txt и THIRD-PARTY-RUST.txt.
Установщик собирается installer\build-installer.ps1 при наличии Inno Setup 7.1.
